# Campus GenAI Studio

AI-powered platform that transforms student ideas into fully executable plans, content, and workflows.

Built for the **AMD Slingshot Hackathon**.

---

## Problem

Students and campus teams often have great ideas but lack a single tool to convert them into organized plans, promotional content, and actionable tasks.

Existing tools are fragmented and require multiple platforms.

---

## Solution

Campus GenAI Studio is a collaborative Generative AI platform that converts a simple idea into:

- Event plan
- Task allocation
- Promotional content
- Sponsor emails
- Landing page code

All generated instantly using AI workflow pipelines.

---

## Core Features

- AI Event Builder
- Multi-step AI workflow generation
- Poster & promotional content generation
- Sponsor email drafting
- Automatic task allocation
- Landing page HTML generator
- Structured JSON outputs
- Collaborative workspace

## How It Works

1. User enters an idea  
2. AI workflow engine processes the request  
3. Structured outputs are generated  
4. Results are displayed in the dashboard

Outputs include:

- Event plan
- Tasks
- Marketing content
- Sponsor email
- Landing page code

---

## AI Workflow Concept

Idea → Prompt Pipeline → LLM → Structured JSON → Application Output

---

## Why It Is Different

Unlike traditional AI chat tools, Campus GenAI Studio produces **execution-ready outputs** instead of just text.

It acts as an **AI workflow engine** for student teams.
